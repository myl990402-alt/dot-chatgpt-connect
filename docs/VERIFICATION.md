# 验收：不要把“在线”当作“可用”

发布前记录 Windows、PowerShell、应用、Codex 与代理客户端版本，使用自己的无敏感测试数据。

- 配置：确认本机版本支持 `respect_system_proxy`，启用后完全重启应用，观察首次连接是否仍反复重连。至少重复三次冷启动。
- 网络：确认相关服务经所选路由完成 TLS 并返回 HTTP；认证错误单列。
- 桌面：启动器可发现当前版本、正确显示错误，已有应用时立即打开。
- Dot：创建一个只含随机测试文字的本地文件，明确授权 Dot 读取该文件，要求它返回准确内容。记录工具回执和结果。
- 新对话：如需测试，只提交一次；记录返回的对话 ID，并在本地列表核对。没有 ID 或列表无响应，状态为未确认。
- 稳定性：需要八小时验收时，保存覆盖完整八小时的连接与任务记录；缺失时段不计为通过。没有新样本时，不能评价识别准确率或时效。
- 回退：在测试配置副本上验证恢复；真实配置发生后续编辑时，工具应拒绝覆盖。

0.1.0 不宣称通过了 Dot 端到端、五次重连消失或八小时稳定性验收。单次 HTTP 诊断不是上述验收的替代品。
