# GitHub 发布清单

本项目建议仓库名 `dot-chatgpt-connect`，许可证 MIT，初始状态标注 experimental。发布是用户后续操作，本交付不包含创建远程仓库或上传。

1. 在干净目录解压源码包。只使用示例配置，检查没有用户名、本机绝对路径、订阅、节点密码、令牌、聊天记录或日志。
2. 用 PowerShell 7.4+ 运行离线测试。CI 可直接执行 `./tests/Run.ps1`。
3. 在真实 Windows 环境完成文档中的验收矩阵；记录已通过和未通过项目，勿将未验证写成修复成功。
4. 审核 `.gitignore`，确认 `data/`、`config.local.json`、`.lnk` 不在提交中。不要用 `git add -f` 添加本机数据。
5. 发布源码、README 和版本说明。代理地址、应用路径均由用户配置或自动发现，不打包他人的代理客户端、账户配置或登录状态。
6. 后续如果内部服务域名、安装包名称或特性支持发生变化，更新说明和测试矩阵。

反馈问题时，请提供已脱敏的版本信息、所选代理模式、curl 错误码和工具产生的诊断结果。不要公开原始 Codex 配置或整个桌面日志。
